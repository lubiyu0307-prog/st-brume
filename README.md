# 黑森林 Forêt-Noire — SillyTavern 甜點感深色主題

把 SillyTavern 換上一層黑森林巧克力：可可盤面、蛋糕體層次、
鮮奶油細線、酸櫻桃點綴。**全主題零模糊**——你的背景圖保持清晰。

## 特色

- **完整覆蓋**：聊天、設定、角色頁、世界書、彈窗、提示、表單控件全部一致
- **零模糊**：不使用 backdrop-filter；設有背景圖時蛋糕層自動轉半透明讓照片透出
- **沉浸模式**（預設開）：九宮圖示列收起，改為「頭貼＋角色名＋一句狀態」的角色頭部；
  工具列點頭部滑桿鈕展開，**功能一個都沒少**
- **手機優先**：世界書欄位在窄螢幕排成 2×2、面板貼齊螢幕；輸入列永不被右緣截斷
- **巧克力屑底紋**可關；**緊湊行距**可切
- **角色卡相容**：MVU／regex 渲染的狀態欄照卡片原設計呈現（訊息內文不以 !important 侵入）

## 安裝

SillyTavern →「擴充功能」→「Install extension」→ 貼上：

```
https://github.com/lubiyu0307-prog/st-brume
```

裝好即完工，不需另外設定「介面主題」。設定在「擴充功能」頁的 **黑森林** 區塊。

> 與其他主題類擴充（如 Moonlit Echoes Theme）同時啟用會互相覆蓋，建議擇一。

## 相容性

SillyTavern 1.12+（設定經 `SillyTavern.getContext()` 儲存，舊版退回 localStorage）。
純外觀層——不碰訊息處理、regex、變數、世界書邏輯。
