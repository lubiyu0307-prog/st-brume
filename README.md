# 黑森林 Forêt-Noire

SillyTavern 介面擴充。**兩套一鍵切換的 skin**、一個**看得見的上下文儀表板**，
以及三顆讓你少滑好幾下的按鈕。

全主題**零模糊**——不使用 `backdrop-filter`，你的背景圖保持清晰。

---

## 兩套 skin

在「擴充功能 → 黑森林 → Skin」切換。**功能完全相同**，換掉的是整套視覺語彙——
顏色、圓角、字體、裝飾、連等回覆的動畫都不一樣。

### 🍒 黑森林 Forêt-Noire（預設）

可可盤面、蛋糕體層次、鮮奶油細線、酸櫻桃點綴。圓角、圓體字。
等回覆時，有一顆櫻桃在巧克力軌道上滾。

| 用途 | 色 |
|---|---|
| 盤面 | `#241713` / `#1B100D` |
| 蛋糕體（面板） | `#33211C` |
| 甘納許（浮起層／輸入框） | `#432D26` |
| 鮮奶油（主文字） | `#F6EFE7` |
| 焦糖（次文字） | `#C9A489` |
| **酸櫻桃（主色）** | `#C8465A` |
| 開心果（啟用狀態） | `#8FAE72` |

### 🛸 正午 · 霧藍 Midi Dusty

1955 年沙漠汽車旅館的曬白色票。平塗、硬邊、零漸層、零陰影——
**2px 霧藍框線是這套的主角**，不是裝飾。幾何無襯線招牌字。
等回覆時，是外星人開飛碟來借隕石。

| 用途 | 色 |
|---|---|
| 砂色頁面 | `#EDDCB2` / `#E4D0A0` |
| 面板 | `#F2E3BC` |
| 明信片（卡片／泡泡） | `#FBF4E2` |
| 板岩藍（主文字／頭尾條） | `#43596B` |
| 霧藍（框線） | `#5B7A92` |
| **燒橘（主色）／鏽橘（強調字）** | `#E4632A` / `#B0431A` |
| 土耳其藍綠（次要點綴） | `#166D7D` |

> 對比是量出來的，不是配出來的：奶油 `#F4E6C0` 壓板岩 **6.65:1**、
> 板岩內文壓明信片白 **6.65:1**、壓砂底 **5.73:1**、霧藍框線壓面板 **3.55:1**
> （內文門檻 4.5:1、非文字 3:1）。

## 上下文儀表板

頭部那顆百分比 ＝ 送給 AI 的「行李箱」裝了幾成。**點它**展開明細。

- **五個分項**：聊天記錄／角色卡／世界書／人設／其他，各佔多少一目了然
- **數字對得起來**：送出過訊息之後，數值直接取自酒館自己的提示詞帳本，
  與內建「提示詞項目化」逐位一致；還沒送出過則標示為「估算」
- **白話提醒**：有幾則被收成幽靈、該不該壓記憶、上下文長度是不是被別的擴充改掉了
- 到 100% 不會壞，只是最舊的劇情會掉出模型視野——那就是該做記憶的時候

資料全部取自 ST 開放的 API（`maxContext`／`getTokenCountAsync`／
`getCharacterCardFields`／`getWorldInfoPrompt`／`chat`），沒有逆向、不讀私有變數。

## 三顆順手的按鈕

| 按鈕 | 做什麼 |
|---|---|
| **📖 做記憶** | 一鍵把「上次整理到的地方 → 最新一則」壓成記憶存進世界書，不用滑到頭再滑到尾設範圍 |
| **▶▶ 再來一段** | 不用打字，他就接著剛才的劇情開新泡泡演下去。不是重寫，草稿也不會被吃掉 |
| **📋 複製正文** | 只複製敘述與對話，不含狀態欄的 HTML，貼到哪裡都乾淨 |

前兩顆在輸入列左側，第三顆在每則訊息上。**偵測不到對應指令時會自動隱藏**——
例如沒裝 [Memory Books（STMemoryBooks）](https://github.com/aikohanasaki/SillyTavern-MemoryBooks)
就不會出現「做記憶」。

## 其他

- **沉浸模式**（預設開）：九宮圖示列收起，改為「頭貼＋角色名＋一句狀態」的角色頭部；
  工具列點頭部滑桿鈕展開，**功能一個都沒少**
- **手機優先**：世界書欄位在窄螢幕排成 2×2、面板貼齊螢幕；輸入列永不被右緣截斷；
  Android 的系統列跟著 skin 染色
- **角色卡相容**：MVU／regex 渲染的狀態欄照卡片原設計呈現（不以 `!important` 侵入訊息內文）
- **完整覆蓋**：聊天、設定、角色頁、世界書、彈窗、提示詞管理器、表單控件全部一致
- 巧克力屑底紋可關、緊湊行距可切

## 安裝

SillyTavern →「擴充功能」→「Install extension」→ 貼上：

```
https://github.com/lubiyu0307-prog/st-brume
```

裝好即完工，**不需要另外設定「介面主題」**。設定在「擴充功能」頁的 **黑森林** 區塊。

## 設定項目

| 項目 | 預設 | 說明 |
|---|---|---|
| 套用主題 | 開 | 關掉即還原成酒館原樣 |
| Skin | 黑森林 | 黑森林 ／ 正午 · 霧藍 |
| 沉浸模式 | 開 | 收起工具列，改用角色頭部 |
| 巧克力屑底紋 | 開 | 設有背景圖時自動讓位 |
| 緊湊行距 | 關 | |
| 上下文用量 | 開 | 頭部顯示百分比，點開看細項 |
| 主題快捷按鈕 | 開 | 做記憶／再來一段 |
| 複製正文按鈕 | 開 | 每則訊息加一顆 |
| 空回診斷 | 關 | 回覆是空的時候說明原因（唯讀觀察，不改請求／回應） |

## 相容性

SillyTavern 1.12+（設定經 `SillyTavern.getContext()` 儲存，舊版退回 localStorage）。
純外觀層——不碰訊息處理、regex、變數、世界書邏輯。

> ⚠️ 與其他主題類擴充（如 Moonlit Echoes Theme）同時啟用會互相覆蓋，建議擇一。
